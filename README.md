# C++ 课程大作业：图形化贪吃蛇

这是一个基于 **C++17** 和 **EasyX 图形库** 开发的贪吃蛇游戏。
本项目是 [C++面向对象程序设计] 的课程作业。

## 📝 完成情况

在基础贪吃蛇功能之上，我额外实现了以下扩展功能：

1.  **图形化界面**：使用 EasyX 库替代控制台字符，支持图片素材渲染。
2.  **完整游戏流程**：实现了主菜单、地图选择、设置界面、游戏结束结算。
3.  **道具系统**：
    * 设计了基于多态/枚举的道具管理。
    * 实现了减速、断尾、双倍积分、幽灵模式（无敌/穿墙）等多种道具效果。
    * **技术点**：实现了 PNG 图片的透明通道混合算法 (`putimage_alpha`)。
4.  **数据持久化**：
    * 支持存档/读档（二进制文件读写）。
    * 支持最高分记录和配置文件保存。
5.  **视觉与反馈**：
    * 实现了简单的粒子系统（吃食物/断尾时的爆炸效果）。
    * 添加了音效和背景音乐支持。

## 💻 开发环境

* **IDE**: Visual Studio 2022
* **语言标准**: C++17
* **依赖库**: [EasyX Graphics Library](https://easyx.cn/) (请确保在 VS 中安装了 EasyX)

## 🎮 操作说明

* **W/A/S/D**：控制蛇的移动方向。
* **空格键**：暂停游戏。
* **ESC**：保存进度并返回主菜单。
* **Enter**：菜单确认。
